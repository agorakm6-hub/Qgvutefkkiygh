# Crown Casino — обновление: профили, монета Genesis, /db, звуки

## Что положить на сервер
Архив плоский — никаких папок. Распакуй всё прямо в корень репозитория / рядом с `server.js`, с заменой:

| Файл | Что это |
|---|---|
| `server.js` | подключены модули профилей, /db, звуков, розыгрыш монеты |
| `crown_casino_app.html` | мини-приложение (профиль по клику на аватарку, новые звуки, события) |
| `en.json`, `ro.json`, `ru.json` | +27 строк `prof_*` |
| `groupgames.js` | статистика групповых игр + значок монеты у ника |
| `profiles.js` | профиль 2.0, монета Genesis, рейтинги, подарки, команды бота |
| `profilecard.js`, `profilecard_draw.js` | рисование карточки в PNG |
| `dbbackup.js` | команда /db |
| `pepe_coin.png`, `pepe_happy.png`, `pepe_sad.png`, `Inter-Bold.otf`, `Inter-Medium.otf` | монета, лица Пепе, шрифты Inter (для картинки профиля) |
| `SOUNDS_README.txt` | инструкция по звукам (сами mp3/ogg кладутся рядом с `server.js`) |
| `package.json` | зависимости |

**Установка:** `npm install` (добавилась одна зависимость: `@napi-rs/canvas` — готовые бинарники, системных пакетов не нужно).
`crown_casino_preview.html` — только для просмотра дизайна в браузере (переводы уже подставлены). На сервер его класть не надо.

## Монета Genesis Pepe Coin
- Ровно 50 штук (#1…#50), купить нельзя. С первого запуска все 50 у админа.
- Каждые 20 игроков в реестре — одна монета случайному игроку (сначала тем, у кого монеты ещё нет). Игроку и админу приходит уведомление.
  Если на момент деплоя игроков уже ≥ 20, недостающие розыгрыши пройдут при появлении следующего нового игрока.
- Админ: `/coin` — кто чем владеет; `/coin give @user [номер]`; `/coin take @user`.
- Что даёт: карточка с Genesis-фоном, золотой рамкой, монетой и номером «#7 из 50», титул Genesis Holder, значок 🪙 в рейтингах и рядом с ником в групповых играх. Только косметика — на игру не влияет.

## Профиль
- Мини-приложение: клик на иконку аватарки → профиль (карточка, оформление, рейтинги, «Поделиться»). Окно «Уровни и награды» теперь кнопкой внутри профиля.
- Бот (личка и группы): `профиль` / `/profile` (ответом на сообщение — чужой профиль), `топ` / `/top`, `предметы` / `/items`, `подарить frame:gold` / `/gift …` (ответом на сообщение, 3 в день).
- Инлайн: в любом чате `@бот profile` → карточка-картинка. Нужен публичный `EXTERNAL_URL` (https) и включённый inline-режим в BotFather.
- Чтобы команды без слэша (`профиль`, `топ`) работали в группах: сделай бота админом группы или выключи Group Privacy в BotFather.
- Титулы/рамки/фоны открываются по достижениям (подсказки в приложении) или дарятся.

## /db — резервная копия
`/db` (только админ) → две кнопки:
- **Получить БД** — один файл `crown_db_….json.gz` со всем: игроки, балансы, банк, очки, профили и монеты, курс крипты, позиции, история Crash, групповые игры и т.д.
- **Загрузить БД** — пришли такой файл → бот покажет, что внутри → «Применить». Данные перечитываются сразу, перезапуск не нужен. Перед заменой бот сам делает копию в `backups/` (последние 5).
Ограничение Telegram: бот скачивает файлы до 20 МБ (gzip сжимает сильно, обычно хватает с большим запасом).

## Звуки
Бот-сервер отдаёт звуки, лежащие рядом с `server.js` (если создашь папку `sounds/` — берёт из неё); клиент сам находит их. Схема имён и где взять бесплатные CC0-пакеты — в `SOUNDS_README.txt`.
Пока файлов нет, играют запасные синтезированные звуки (у каждой игры свои), т.е. ничего не ломается.

## Честные ограничения
- Рекорды (Crash/Flappy/выигрыш) в мини-приложении присылает клиент — сервер проверить их не может, их можно подделать. В рейтингах они без галочки. Рейтинг «Игры в чатах» считает сам сервер (с галочкой).
- Правила «Лесенки» и «Точного исхода» в групповых играх по-прежнему не заданы (кнопки выключены).

## Письма о кредите (картинка от «CrownCasino.com» в личку бота)
- При выдаче кредита игроку приходит картинка-договор: сумма, ставка, сумма к возврату, даты выдачи и погашения.
- За сутки до срока приходит красное напоминание: остаток, сколько часов осталось и что будет при просрочке (долг замораживается на балансе, новые кредиты недоступны, пока админ не снимет запрет).
- Проверка напоминаний — раз в 10 минут. Если игрок заблокировал бота, будет 3 попытки и всё. Язык письма — тот, что игрок выбрал в боте.
- `/loanletter` (только админ, в личке) — пришлёт оба письма с тестовыми цифрами, чтобы посмотреть, как они выглядят в Telegram.
- Файлы: `loanmail.js` (отправка и таймер), `loanletter.js` (рендер PNG), `loanletter_draw.js` (рисование). Нужен `@napi-rs/canvas` (уже в `package.json`); без него придёт короткий текст вместо картинки.
